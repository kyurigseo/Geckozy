## 1. 서비스 소개

### 도마뱀을 위한 스마트 사육장 코치

도마뱀을 처음 키우는 사육자가 입양 전 적절한 사육환경을 준비하고, 입양 후에는 IoT 센서를 통해 사육장의 온도, 습도와 조명을 지속적으로 관리할 수 있도록 돕는 스마트 케어 서비스입니다.

키우는 종과 사육 환경을 기준으로 현재 환경이 적절한지 알려주고, 필요한 관리 행동을 제안합니다.

장기적으로는 사육환경 데이터와 먹이, 탈피, 배변, 체중 등의 기록을 함께 축적하여 병원 진료 시 활용할 수 있는 케어 데이터로 확장하고자 합니다.

## 3. 타겟 유저

### 1차 타겟

- 크레스티드 게코, 레오파드 게코 등 도마뱀을 처음 입양하거나 사육 경험이 많지 않은 초보 사육자
- 종에 맞는 온도·습도·조명 환경을 어떻게 구성해야 하는지 어려움을 느끼는 사용자
- 학교·직장·외출 등으로 사육장을 계속 확인하기 어려운 사용자
- 인터넷과 커뮤니티에 흩어진 사육 정보를 반복적으로 찾아보는 사용자

### 확장 타겟

- 여러 개체 또는 여러 사육장을 관리하는 도마뱀 사육자
